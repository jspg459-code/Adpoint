# AdPoints

Code source du projet **AdPoints**.

Ce dépôt sert de base de travail et de sauvegarde pour le site déployé sur Vercel.

## Stack
- Next.js
- React
- Supabase
- Vercel

## Variables d'environnement
Créer un fichier `.env.local` avec :

```
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
```

⚠️ Les clés ne doivent jamais être ajoutées directement dans GitHub.
